# مولفه های PEAS

Performance Measure:
    درصد خواندن و توجه کردن کاربران به پیشنهاد ها، دقت پیشنهاد ها، رضایت کاربران

Environment:
    کاربران، کتاب ها، ویژگی های کتاب ها، امتیاز های کاربران به کتاب ها

Actuators:
    ارائه کتاب پیشنهادی به کاربر

Sensors:
    دریافت اطلاعات و سوابق خواندن و امتیاز های داده شده کاربر، دریافت ویژگی های کتاب
