# ai-lab-051
پروژه و تمارین مربوط به آز هوش مصنوعی دانشگاه باهنر شیراز ترم 051


# مولفه های PEAS

Performance Measure:
    درصد خواندن و توجه کردن کاربران به پیشنهاد ها، دقت پیشنهاد ها، رضایت کاربران

Environment:
    کاربران، کتاب ها، ویژگی های کتاب ها، امتیاز های کاربران به کتاب ها

Actuators:
    ارائه کتاب پیشنهادی به کاربر

Sensors:
    دریافت اطلاعات و سوابق خواندن و امتیاز های داده شده کاربر، دریافت ویژگی های کتاب


# ویژگی های محیط

محیط کاملا قابل مشاهده: تمام اطلاعات مورد نیاز مدل قابل مشاهده و در دسترس است.

تک عامله: فقط یک عامل در محیط است که کتاب ها را به کاربران توصیه میکند.

قطعی: همیشه با ورودی های یکسان، خروجی نیز یکسان است.

ترتیبی: پیشنهاد و اعمال عامل می تواند روی آینده تاثیر بگذارد. اگر کاربر از پیشنهاد عامل خوشش آمد، عامل در آینده بهتر تصمیم می گیرد.

پویا: ممکن است هنگام تصمیم گیری عامل محیط تغییر کند. مثل امتیاز دادن کاربر

گسسته: ویژگی های کتاب ها و کاربران و امتیاز های کاربران گسسته هستند و پیوسته نیستند.
